# Clippy Vision v2.1.1

Setup is more reliable on Linux, and the app no longer hangs on the loading screen. In-app chat was removed, and you can ask about your activity from Cursor, Claude Desktop or VS Code instead. Tested on Windows and Linux.

## What's new

### Removed
- **In-app chat.** Ask about your activity from Cursor, Claude Desktop or VS Code through **Settings → Connect apps**. Capture and your session timeline are unchanged. ([#65](https://github.com/protocorn/clippy-vision/pull/65))

### Fixed
- Setup now installs Python packages into an app-managed environment, and Linux shows clear errors when `zstd` or the Ollama installer fails. ([#62](https://github.com/protocorn/clippy-vision/pull/62))
- Fixed a Linux install failure caused by `pynput`/`evdev`. ([#63](https://github.com/protocorn/clippy-vision/pull/63))
- Fixed the app getting stuck on the loading screen. ([#64](https://github.com/protocorn/clippy-vision/pull/64))

## Install

1. Install **Python 3.11+**.
2. Download the file for your OS below.
3. Setup asks you to download an Ollama model, which writes your session summaries.
4. **Windows:** if SmartScreen warns, choose **More info → Run anyway**.
5. **Linux:** `chmod +x ClippyVision-Linux-x86_64-2.1.1.AppImage`, then run it. Optional capture helpers: `xdotool`, `x11-utils`, `xprintidle`, `xclip`/`xsel`/`wl-clipboard`. If it won't launch, install `libfuse2` (needed on Ubuntu 22.04 and newer).

## Release Assets

Both builds are unsigned. macOS isn't included in this release.

- `ClippyVision-Windows-Setup-2.1.1.exe`
- `ClippyVision-Linux-x86_64-2.1.1.AppImage`
