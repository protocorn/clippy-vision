# Device soak reports

Manual end-to-end reports from running Clippy Vision on real machines.

Use this folder for contributions that are **testing reports**, not code changes. Prefer the branch noted in the related GitHub issue (usually `dev/rag-ocr-capture` until it merges).

## How to contribute

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to a new file named:

   `YYYY-MM-DD-<your-github-username>.md`

   Example: `2026-08-16-alice.md`

2. Fill every section. Honest failures are as useful as successes.

3. Open a PR that adds only your report file under this folder.

## What we want

- Capture left on for about 10 minutes while you do normal work
- At least 5 chat messages that exercise memory / recent activity
- Notes on hardware, OS, model used, and anything that felt wrong
