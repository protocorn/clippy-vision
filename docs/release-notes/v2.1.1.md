# Clippy Vision v2.1.1 Release Notes

Patch release on top of [v2.1.0](https://github.com/protocorn/clippy-vision/releases/tag/v2.1.0): four fixes since that tag, plus removal of in-app chat.

**Version:** `v2.1.1`

**Included Platforms:** Windows NSIS installer and Linux AppImage (unsigned). macOS installers are not included (opt-in workflow only).

This release was **CI-tested only**. There has been **no real-machine testing** for v2.1.1. The Windows installer and Linux AppImage are **unsigned**.

## Changes since v2.1.0

### Removed
- **In-app chat** ([#65](https://github.com/protocorn/clippy-vision/pull/65)) — Chat UI, `/chat` / `/chat/stream`, and related frontend/backend code are gone. Capture, Day Cards, and Connect apps stay. Ask about your activity via **Settings → Connect apps** (MCP from Cursor, Claude Desktop, or VS Code).

### Fixed
- **Setup Python venv + Linux Ollama errors** ([#62](https://github.com/protocorn/clippy-vision/pull/62)) — Installs packages into an app-managed virtualenv (avoids PEP 668/`--break-system-packages`). On Linux, missing `zstd` and Ollama installer failures show clear wizard errors.
- **Linux `pynput` / `evdev` install failure** ([#63](https://github.com/protocorn/clippy-vision/pull/63)) — Installs `pynput` without `evdev` on Linux; pip error summary ignores harmless marker lines.
- **Loading screen hang** ([#64](https://github.com/protocorn/clippy-vision/pull/64)) — Missing `chatBtn` imports no longer leave the window stuck on “Opening Clippy Vision”.
- **Contributor wall duplicates** ([#61](https://github.com/protocorn/clippy-vision/pull/61)) — Case-insensitive GitHub logins are de-duplicated in the README contributors list.

## Install notes (unsigned builds)

Same as v2.1.0:

1. Install a system **Python 3.11+** (not bundled).
2. Download the asset for your OS from this release.
3. **Windows:** SmartScreen may warn (“Windows protected your PC”). Choose **More info → Run anyway**.
4. **Linux:** `chmod +x ClippyVision-Linux-x86_64-2.1.1.AppImage`, then run it. Optional capture helpers: `xdotool`, `x11-utils`, `xprintidle`, `xclip`/`xsel`/`wl-clipboard`.

## Release Assets

1. **`ClippyVision-Windows-Setup-2.1.1.exe`** (unsigned)
2. **`ClippyVision-Linux-x86_64-2.1.1.AppImage`** (unsigned)

macOS installers are not included.
