# Connect Clippy Vision to Cursor

Clippy Vision has no chat box of its own. You ask about your activity through a connected MCP client. This guide walks through connecting Clippy Vision to Cursor.

Before you start:
- Clippy Vision is installed and has completed its setup wizard.
- Cursor is installed.

If Clippy Vision is not connected yet, start with the overview in [mcp.md](../mcp.md).

---

## 1. Connect with one click

1. Open Clippy Vision.
2. Go to **Settings → Connect apps**.
3. Find the **Cursor** row.
4. Click **Connect**.
5. Cursor should open an MCP installation prompt. Review the server details and approve the installation if prompted.

**What Connect does:**

The `connectMcpClient` implementation in `electron-ui/electron/lib/mcp.js` handles the Cursor connection:

1. It writes a `clippy-vision` entry under the `mcpServers` key in Cursor's global MCP configuration file: `~/.cursor/mcp.json`.
2. It opens Cursor's MCP installation prompt using a `cursor://` link.
3. Existing MCP server entries are preserved when the configuration is updated.

The configuration file is written before Cursor's installation prompt opens. If the prompt does not open, check whether the configuration file was created and use the manual setup below.

## 2. Configure Cursor manually

If one-click setup does not work, you can add the Clippy Vision server manually.

### Global configuration

Cursor's global MCP configuration file is:

`~/.cursor/mcp.json`

This configuration is available across your Cursor projects.

### Project-specific configuration

For a configuration limited to one project, use:

`.cursor/mcp.json`

Create the `.cursor` directory in your project if it does not already exist.

### Add the Clippy Vision configuration

1. Open Clippy Vision.
2. Go to **Settings → Connect apps**.
3. Click **Copy JSON**.
4. Open the global or project-specific Cursor configuration file.
5. Add the copied Clippy Vision entry under `mcpServers`.
6. Preserve any other MCP servers already configured.
7. Save the file.

Example structure:

```json
{
  "mcpServers": {
    "clippy-vision": {
      "command": "YOUR_PYTHON_PATH",
      "args": [
        "YOUR_CLIPPY_MCP_SERVER_PATH"
      ],
      "env": {
        "CLIPPY_DATA_DIR": "YOUR_CLIPPY_DATA_DIRECTORY",
        "PYTHONPATH": "YOUR_CLIPPY_RESOURCES_DIRECTORY",
        "PYTHONIOENCODING": "utf-8",
        "PYTHONUTF8": "1"
      }
    }
  }
}
```

The values above are placeholders, not working paths. Use the actual configuration generated by **Copy JSON** on your computer. Do not guess or copy paths from another machine.

If your configuration already contains other servers, add `clippy-vision` inside the existing `mcpServers` object instead of replacing the entire file.

## 3. Restart or reload Cursor

After adding the configuration:

1. Save `mcp.json`.
2. Reload or restart Cursor so it can detect the updated MCP configuration.
3. If Cursor displays an installation or approval prompt, review and approve it.

## 4. Check that the tools appear

1. Open Cursor.
2. Open **Settings → Tools & MCP**.
3. Find the Clippy Vision MCP server.
4. Check whether the server is connected and its tools are listed.

If the tools do not appear:

- Confirm that the configuration file contains valid JSON.
- Check that the configuration uses the `mcpServers` key.
- Confirm that the Python executable and Clippy Vision server paths in the configuration exist.
- Confirm that Clippy Vision has completed its setup wizard and its data directory exists.
- Open Cursor's **Output** panel and select **MCP Logs** to inspect connection errors.
- Check the Cursor MCP documentation for current settings and troubleshooting instructions.

## 5. Test the connection

Open a Cursor chat and ask questions about your recorded activity.

Try these questions:

- "What was I working on yesterday afternoon?"
- "Which websites did I visit yesterday?"
- "What error did I encounter in my terminal recently?"
- "What happened in the last hour?"

A good answer should summarize the recorded activity and identify relevant applications and time periods rather than giving a generic response.

If the answer says there is no recorded activity, check Clippy Vision's timeline to confirm that capture was running during the requested period. An empty result does not necessarily mean the MCP connection is broken.

## 6. Privacy note

Cursor's cloud models may receive information returned by Clippy Vision's MCP tools. The Clippy Vision privacy redactor still runs on every tool reply before it is returned to the client.

Review what information you share with AI clients. Redaction may not detect every sensitive detail.

See [mcp.md — Access permissions](../mcp.md#access-permissions) for more information.

---

## 7. Disconnect Clippy Vision

To disconnect:

1. Open Clippy Vision.
2. Go to **Settings → Connect apps**.
3. Click **Disconnect** in the Cursor row.

You can also remove the `clippy-vision` entry from `mcpServers` in `~/.cursor/mcp.json` or your project's `.cursor/mcp.json`.

Restart or reload Cursor after manually editing the configuration.
